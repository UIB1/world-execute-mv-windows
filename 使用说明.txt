world.execute(me); — ASCII MV
Windows 终端版

适用于 64 位 Windows 10 和 Windows 11（x64）。
完整解压 ZIP 后，可双击 play.cmd，或在 PowerShell / Windows Terminal 中进入解压目录并执行：

    .\play.cmd

按空格或 Enter 开始播放。需要直接播放时，可执行：

    .\play.cmd --autoplay

从指定秒数开始播放：

    .\play.cmd --start 158.7 --autoplay

播放包内含运行时、原曲和双语字幕，可离线使用。
终端尺寸至少需要 65 列 × 24 行，建议最大化窗口或缩小终端字号。

空格 / Enter   播放或暂停
← / →         后退或前进 5 秒
1–5           跳转章节
R             从头播放
, / .         上一句或下一句字幕
[ / ]         字幕提前或延后 0.1 秒
+ / -         调整音量（默认 30%，每次调整 5 个百分点）
H             显示帮助
Q / Esc       退出

原曲与歌词为 Mili《world.execute(me);》。
